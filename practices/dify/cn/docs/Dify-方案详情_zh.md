# Dify LLM 应用开发平台

> 文档类型：华为云解决方案实践方案详情
> 站点与区域：cn（中国站），cn-north-4（华北-北京四）

## 1. 方案概述

Dify 是面向大模型应用开发的社区平台。本解决方案实践保留三套经用户确认曾完成实际云上验证的 RFS 模板：单机标准版、CSS 增强版和高可用版。所有资源和版本描述均以现有 Terraform 为准；调用的公开 OBS 启动脚本不属于仓库可审计内容。

## 2. 架构

```text
标准版：互联网 → EIP → Ubuntu 22.04 ECS → Dify（OBS 启动脚本）

CSS 版：互联网 → 两个 EIP → Dify ECS + 模型 ECS
                                  └────────→ CSS Elasticsearch 7.10.2（VPC 内）

HA 版：互联网 → ELB HTTP/80 → CCE Turbo v1.31（3 节点）→ Dify 工作负载
                                  ├→ RDS PostgreSQL 16 主备
                                  ├→ DCS Redis 6 高可用
                                  ├→ CSS Elasticsearch 7.10.2（三节点）
                                  └→ NAT 出站 / 可选模型 ECS
```

| 方式 | 主要资源 | 公网入口 | 适用边界 |
|---|---|---|---|
| 标准版 | 1 ECS，默认 `x1.8u.16g`、100 GB SAS、1 EIP | 80/443/8000 | 单机部署；无计算和状态层冗余 |
| CSS 增强版 | 标准版 + 模型 ECS + 单节点 CSS | 80/443/8000/11434/9997 | 需要 CSS 向量存储及模板模型节点时 |
| 高可用版 | CCE 3 节点、ELB、NAT、RDS 主备、DCS HA、3 节点 CSS、3 EIP | ELB HTTP/80 | 需托管状态服务与 CCE 承载时；不是跨 Region 容灾 |

## 3. 方案优势

- **保留已验证模板：** 三个既有模板按原有资源和部署路径交付，避免以静态“优化”替换用户已验证的行为。
- **分层选择：** 从单 ECS 到 CSS 与 CCE 托管数据服务，按业务所需选择复杂度。
- **统一编排：** 每个方式通过一个 RFS 资源栈创建对应基础设施，便于审阅、部署和卸载。
- **明确证据边界：** Terraform 中可读的资源、端口和变量被记录；外部 OBS 安装脚本的内部实现、模型细节和运行时行为不作推断。

## 4. 关键实现事实

标准/CSS 默认 Dify 为 `1.8.1`，允许版本清单为 `1.8.1`、`1.6.0`、`1.4.1`、`1.1.3`、`0.15.8`；HA 默认 `1.7.1`，允许 `1.7.1`、`1.4.1`、`0.15.8`。HA 在非 0.x 版本创建 plugin 数据库与 plugin daemon，并以四个必填敏感变量 `plugin_dify_inner_api_key`、`plugin_daemon_key`、`searxng_secret_key`、`sandbox_api_key` 注入对应运行时密钥。DCS 配置自动备份，保留 3 天；RDS、DCS、CSS 均位于私网安全组范围。

HA 插件存储使用节点本地 `hostPath`，不能被视为共享或跨节点持久存储。节点维护、Pod 迁移和灾难恢复前必须完成插件数据备份与恢复演练。

## 5. 使用场景

- 快速搭建 Dify 应用、知识库或模型接入验证环境：选择标准版。
- 需要模板中 CSS 向量存储和模型节点：选择 CSS 增强版。
- 需要 CCE 承载应用并使用 RDS、DCS、CSS 托管服务：选择高可用版，并完成容量、备份、故障恢复和本次云测验证。

## 6. 限制与责任

- 资源、规格、价格与区域可售性应以部署时 RFS 执行计划和华为云账单为准；本文不提供固定费用或性能承诺。
- Dify Provider 密钥、ECS/CCE/RDS/DCS 密码、OBS AK/SK 及 HA 的四个运行时密钥必须由客户保管，禁止进入代码、文档、日志和截图。
- 标准/CSS 的多个端口按原模板对公网开放；生产上线应完成入口收敛、TLS、访问控制、备份和监控审查。
- HA 当前入口是 HTTP，且 CCE API 使用 EIP；需按组织策略评估公网暴露并限制访问。历史云测不替代本次部署验证。
